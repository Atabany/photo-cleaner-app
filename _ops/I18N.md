# Translated pages (fr, de, es): rules

Read `_ops/SEO-PLAYBOOK.md` first (facts, the "never" list, shared chrome). These rules add to it.

## Layout

- English stays at the root. A translation lives at `/<lang>/` with **the same path and file name**:
  `guides/delete-burst-photos-iphone.html` -> `fr/guides/delete-burst-photos-iphone.html`. Never rename a slug.
- Translated (17 pages): `index.html`, `about.html`, `support.html`, `tools/storage-calculator.html`, all of
  `guides/` (10) and all of `compare/` (4). English only: `privacy.html`, `terms.html`, `press.html`, `404.html`;
  link to the English ones and add the language's "(in English)" note to the link text.
- `<html lang="fr">` (or `de`, `es`), `og:locale` `fr_FR` / `de_DE` / `es_ES`, JSON-LD `"inLanguage"` the language.
  Canonical is the page's own URL: `https://getphotocleaner.com/fr/guides/<slug>.html`, home `https://getphotocleaner.com/fr/`.
  `og:url` the same. Keep an empty `<!-- hreflang -->` / `<!-- /hreflang -->` pair right after the canonical;
  `python3 _ops/hreflang.py` fills it.
- Chrome: copy `_ops/chrome/en.html` to `_ops/chrome/<lang>.html`, translate the visible text, alt text and
  aria-labels, and point every link to a translated page at `{root}<lang>/...` (assets stay `{root}assets/...`,
  English-only pages stay `{root}privacy.html` etc.). `{root}` is the path to the **site root**, so on
  `fr/guides/x.html` it is `../../`. Inside page bodies, relative links between translated pages work as in English
  (`../guides/...`, `guides/...`); assets and English-only pages need the extra `../`.
- App Store links keep Apple's campaign format; `python3 _ops/appstore_campaign.py` sets `ct=web-<lang>-...`.
- Do not edit `sitemap.xml`, `llms.txt`, `llms-full.txt`, `robots.txt`, `assets/`, English pages or any `_ops/` file
  other than `_ops/chrome/<lang>.html`. The coordinator updates the shared files after merging.

## Wording

- Translate for a native reader: natural, idiomatic, informal-polite as Apple writes in that language (fr: "vous";
  de: "du", as the app does; es: "tú", neutral Spanish for Spain and Latin America). Not word for word. No machine-
  translation tells, no anglicisms where the language has its own word.
- **App names stay as they are**: "Photo Cleaner", "Photo Cleaner: Swipe Cleanup", competitor names, "App Store",
  "iCloud", "Live Photos", "iPhone", "iPad".
- **Photo Cleaner's own labels** (Trash Bin, Similars / Duplicates, Blur Detection, Largest Files, Memory Lane,
  Today's Throwback, Select All, See Pro plans, Restore purchases ...): use the exact string the app shows in that
  language, from `~/indie/PhotoCleaner/PhotoCleaner/Resources/<lang>.lproj/Localizable.strings` (match by the English
  value in `en.lproj`). If the app has no translation for a label, keep the English label and say nothing more.
- **iOS menu names and steps** (Photos, Settings, Recently Deleted, Select, Duplicates, Optimize iPhone Storage ...):
  use Apple's own wording in that language. Take it from Apple's localized pages, the same articles the English page
  cites with the locale swapped (`support.apple.com/fr-fr/...`, `/de-de/`, `/es-es/`; `curl -sL` works). Link to the
  localized Apple page instead of the English one. If you cannot confirm a label on an Apple page, write the
  generic description rather than inventing a menu name.
- Facts never change in translation: 100 free deletions (one-time, does not refill); weekly, monthly, yearly and a
  one-time lifetime option; no free trial; on-device, no account; iOS 17 or later; 10 app languages; rating shown as
  the **US** App Store value with its count, exactly as on the English page. Never print a price or a currency sign.
  Comparison tables keep "—" where the English page has it. Competitor facts are not re-researched: translate what
  the English page states and keep its "checked on" dates.
- Screenshots and the preview video are the English store assets; translate alt text and captions, and where a
  caption quotes text visible in an image keep the English quote.
- Titles <= 60 characters and meta descriptions <= 155 (the validator fails otherwise): rewrite, do not truncate.
  One `<h1>`. FAQPage / Article / BreadcrumbList JSON-LD text must match the translated visible text.
- Dates: "Updated <month year>" in the language; keep the English page's datePublished / dateModified.
- The storage calculator works without JS and its script strings are translated too; number formats follow the
  language (fr "1,5 Go", de "1,5 GB", es "1,5 GB").

## Before committing

`python3 _ops/sync_chrome.py && python3 _ops/appstore_campaign.py && python3 _ops/hreflang.py && python3 _ops/validate.py`
must end with `OK`.
