iPhone Photo Storage Calculator

By Mohamed Elatabany · Updated 18 October 2026

Estimate file bytes by multiplying an item count by its average size in MB, then divide by 1,000 for decimal GB. This calculator does not scan your library or measure recoverable iPhone storage.

Enter non-overlapping groups

Example: 2.4 GB of total file bytes. Videos contribute 2 GB.

Runs in your browser. No entries are sent or stored. The defaults are illustrative assumptions, not measured averages.

Use sizes from your own library

Open an item’s information in Photos and sample a few unwanted examples. Video duration, format and resolution can change the size considerably. Enter photos and screenshots separately so the same file does not appear in two groups.

Why this is not a free-space guarantee

Optimize iPhone Storage can keep smaller local copies while originals remain in iCloud. Full file bytes can therefore differ from bytes stored on this phone. Apple’s Recently Deleted recovery stage also affects the deletion workflow. Check Settings → General → iPhone Storage for actual local usage.

Deleting through iCloud Photos synchronizes across devices using the same library. Keep a separate copy of irreplaceable media and review selections before confirming anything. This calculator cannot access, inspect or delete photos.

Turn the estimate into a review

Start with a small group contributing the largest total file size. Keep meaningful originals even if they are large. Try the large-video guide, screenshot cleanup or duplicate-photo guide, then compare actual device storage.
